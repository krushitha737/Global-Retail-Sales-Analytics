# 🌍 Global Retail Sales Analytics

## 📌 Project Overview

Global Retail Sales Analytics is a data analytics project developed using **Microsoft Power BI** to analyze large-scale retail sales data and extract meaningful business insights.

The project focuses on understanding sales performance, profitability, regional trends, and sales channel effectiveness through interactive dashboards and visualizations.

The dashboard helps users monitor key business metrics and make data-driven decisions.

## 🎯 Project Objectives

- Analyze global retail sales performance.
- Identify high-performing regions and sales channels.
- Evaluate revenue, profit, and units sold.
- Compare online and offline sales performance.
- Identify business trends and patterns.
- Present insights through an interactive Power BI dashboard.

## 🛠️ Technologies Used

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **Microsoft Excel / CSV** – Dataset storage and data handling.
- **DAX** – Calculations and KPI creation, where applicable.

## 📂 Dataset Description

The project uses a Global Retail Sales dataset containing approximately **1,000,000 sales records**.

The dataset includes information related to:

- Region
- Sales Channel
- Units Sold
- Revenue
- Profit
- Total Records

The dataset is analyzed across different geographical regions and sales channels to understand overall business performance.

## 📊 Dashboard Features

The Power BI dashboard provides interactive visualizations covering:

### 1. Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Units Sold
- Total Records

### 2. Regional Sales Analysis
- Revenue by Region
- Profit by Region
- Units Sold across Regions

### 3. Sales Channel Analysis
- Online vs Offline Sales
- Revenue comparison
- Profit comparison

### 4. Business Performance Analysis
- Sales distribution
- Profitability trends
- Regional performance comparison

### 5. Interactive Filters
- Region
- Sales Channel
- Other available dashboard filters
